# v1.32：可读来源证据与回归复测

续接结果新增 `source_evidence`，解决“提示检查来源，却只返回无法在记忆块中解引用的 URI”的缺口。这是只读投影，不是状态抽取、自动确认或效果证明。

## 投影契约

明确选择一个任务后，现有 `resume` CLI、公共 `TaskResumeService` 和 Inspector 共用投影。`source_evidence.authority="unverified_source"`，每个摘录带 canonical `source_ref`、原始 `role`、`created_at`、清洗后的 `text` 和 `truncated`。

- 只读取该任务同 scope、仍有效的直接 Journal 来源；任何任务来源失效或任务被归档/替代后，不用剩余摘录复活任务。
- 仅包含 user-chat 中角色与类型一致的用户/助手消息；不含系统、工具、后台、未来消息或 hash-only 正文。助手自述不是独立验证，用户下达指令不是动作完成。
- 最多取最近 5 条符合条件的消息，按时间顺序展示；每条至多 1000 字符，摘录合计至多 4000 字符。条数或正文受限会显式标记截断；窗口不是完整历史，字符限额也不是完整模型 token 预算。
- 来源扫描遵循 Episode 已有 100 条直接来源上限，每条读取至多 64 KiB 原始字节后再清洗；异常超长来源也标记截断。用字节读取保留 NUL 后的限定语，清洗空消息不占用摘录名额，不因显示限制把已接受状态变成未知。
- 新捕获的检索文本在 native TEXT 绑定前移除 NUL，完整 captured parts 和其审计哈希保留；不自动修复旧库中已经截断的 `normalized_text`。旧案例复测必须从授权材料新建隔离记忆，不能假设升级会恢复历史缺失正文。
- 摘录使用已有投影清洗，屏蔽 Mnemora 包装分隔符、隐藏控制字符和角色伪装。清洗不保证模型不会遵循恶意内容；这些内容始终仅供参考，不能当作指令。
- 不据此填充 `completed`、`next_steps` 等已接受状态字段，不改变 `accepted_current_state_available`、confidence 或数据库内容。`needs_reconfirmation` 可以与可读证据同时存在：前者描述记忆缺少接受状态，不等于真实任务一定无法判断。
- 模糊查询仍返回候选，不把多任务来源拼成一个任务；先明确选择任务再读取证据。

调用方将投影附加给模型时，仍需把它放在引用材料位，检查最终完整提示的 token 预算，并保留实际模型可见载荷。只有 URI 或 formation 日志不能替代载荷检查。

## 已收到的探索包核对（2026-10-01）

开发侧只读检查用户提供的脱敏包，并以当前评估程序重算：36 行，Mnemora 正确 5/12、test 2/6；判决与包内输出完全一致，为 `fail`。实际注册政策仍为 20 tuning / 100 test，回复及 README 的 10/40 是说明错误，不是已授权政策变更。成功案例为 tune:01/03/04 和 test:02/03；test:06 为失败。

原失败样例只有任务目标与 URI，没有可读来源。这证明载荷缺口，不单独证明它导致全部模型失败。形成日志不足以排除提取缺漏；其他三臂提示、输出和 collection/annotation audit 尚未随包提供。

样例真值另有时点问题：续接点为 22:47:10，下一步引用 22:52:29 的完成陈述；把升级指令当作旧版本已经被替代也缺少完成依据。原结果保留不改，待来源核对后另发修订标注与变更理由；不能从后续事件给先前时点补造状态。

## 同批可靠性修复

统一 ContextEngine 召回继续允许 stateless/ignored 会话读取，但不再写入召回次数、访问强化、first-use 装配验证或 unified shadow 记录。`kg_context` 的可选 `recordAccess=false` 贯穿词法、语义、混合及降级记忆搜索；默认调用保持原强化行为和召回结果。此修复不宣称所有宿主功能或其他组件都完全无写入。

合成评估的状态断言仍只检查原状态投影；额外对来源载荷检查禁止文本和出处，不能用未确认摘录让缺失的已接受状态假通过。Inspector 独立显示来源角色、时间及截断，正文按纯文本渲染；异常时间值显示未知，不中断页面。

## Mac agent 的下一次交付

1. 在授权工作区检查真值：每条依据区分“续接点当时可用”与“之后发生”，区分用户请求、助手自述与可核对结果。后续记录可帮助审计，但不能证明续接点已完成。检查无记忆组全对是否由当前问题已含答案、任务不需要历史或标注口径导致；不要直接断言泄漏。
2. 保存原包和原标签。修订稿逐项记录标签变化及理由，补充 collection/annotation audit、各臂公共提示一致性、实际载荷与模型输出；对外只提供获授权脱敏件，不发身份映射、生产库或完整历史。
3. 在隔离环境使用含本修复的明确提交构建，对旧案例作匹配回归复测；固定模型/非记忆提示/预算，并记录新增摘录带来的真实 token 和延迟。保留所有失败与违例。旧案例已经见过，不能重新称作新 held-out。
4. 正式价值实验仍按现有预注册政策执行。在任何正式运行前保留可独立核对时间的外部记录；本地哈希不能代替它。不要事后补注册或降低门槛。材料不足可报告探索性结果，v1.33 门槛保持关闭。

本分支测试只证明投影契约与边界，不证明真实续接正确率提高；不访问 Mac 生产库，也不把受控包中的会话引用、原始摘录或指纹提交到公开仓库。
