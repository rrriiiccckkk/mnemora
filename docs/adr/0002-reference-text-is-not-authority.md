# Reference text does not confer instruction authority

Status: accepted

Stored sources, model summaries and admitted procedures can contain forged
Mnemora delimiters or speaker labels. Admission and provenance establish
eligibility and traceability, not permission for their text to override host
instructions. Apply the shared projection-only guard at ordinary recall,
summary assembly/transcript rewrite and built-in reasoning presentation;
reserve every `MNEMORA_*` envelope, quote role-like lines and remove hidden
controls while preserving audited records. This keeps historical data readable
without trusting the storage location or an operator-confirmed procedure as
an instruction channel. Oversized reasoning presentations are rejected by the
existing byte-limit contract rather than cutting their closing envelope.

Some host interfaces transport reference material through a system message or
system-prompt addition. This decision constrains its representation, not that
transport role, and cannot guarantee model obedience to the boundary. Hosts
remain responsible for tool authorization and consequential-action approval.
