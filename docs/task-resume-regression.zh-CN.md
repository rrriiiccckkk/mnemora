# 一键三臂联调：开始授权一次，结束看报告

日常调试使用此入口，不需要飞书事前记录、外部注册文件或人工标签。
正式效果实验继续使用[原实验流程](task-resume-experiment-runner.zh-CN.md)，
独立事前记录、正式样本与人工审计要求不变。

## 一条命令

准备已有授权的 bundle（格式沿用原工具），使用仓库外私有目录。
形成 Mnemora 载荷仍须隔离、限于同案例截止历史；此入口运行已形成载荷，
不自动读取 OpenClaw 历史、不访问生产库、不偷偷调用抽取或评审模型。

例如，两案例共六格，每格预算 8000 token：

```bash
node scripts/task-resume-experiment.mjs regression \
  /absolute/private/bundle.json /absolute/private/new-run \
  --max-calls 6 --max-total-tokens 48000 --execute
```

通过安全凭据环境提供 `MNEMORA_EXPERIMENT_API_KEY`，不写入 bundle 或参数。
缺少 `--execute`、凭据或完整预算时不会调用模型；预算必须覆盖全部格及
每格完整配置预算。调用上限和总 token 额度随首次授权冻结，不能续跑时扩大。
这是本地额度检查，不是供应商账单硬上限；供应商超限或未知费用仍可能已发生。

工具自动完成材料冻结、局部授权记录、六格串行运行、校验和事实报告。
不生成正式 registration，也不把本地授权记录假称独立事前记录。
同一命令续跑会校验材料、代码和额度，已完成格不再调用；未知调用状态、
损坏记录、截断输出、错误模型或预算违规会停止，不自动重试。

## 结束后看什么

终端只回报状态、计量摘要和私有报告文件名，不打印历史、输出或密钥。
私有报告提供逐格结果、输入/输出/总 token、分臂汇总与完成批次的 token 比。
失败批次的汇总只覆盖有效格，不把零已知 token 解释成零费用。
报告使用内容哈希命名，保留不同阶段快照；不覆盖既有操作者文件。

完成后自动提供 annotation packet。Mac agent 可据包内真值、完整历史与
冻结 rubric 给出 **AI 初评**，直接附在最终摘要中，不需要先请用户逐项审批。
初评不是人工复核；证据不足写未知，不能因无记忆组缺材料就自动把澄清判正确。
工具本身不额外发起 AI 裁判调用、不自动生成四项正确性标签。

只有发现异常、未知费用、缺凭据或材料缺口时请求用户处置。
普通成功批次直接报告结果，无须额外“验包文案”和反复授权。

## 不能做什么

- 回归工作区冻结 `purpose=regression`，不改真实材料的 kind。
- 正式注册 gate 和 measured export 拒绝回归工作区；报告始终标
  `efficacy=not_established`、`eligibleForPilotReview=false`。
- 不把已看案例计入全新 held-out，不从小样本放行 v1.33。
- 不将输入与输出 token 的合计差异直接归因于载荷体积；形成成本、
  评审成本和生产端到端耗时不在本报告内。

版本或材料有变化时新建工作区。不要删除记录、清除未决 lock 或修改额度来
重跑同一批；新的付费尝试须重新获得授权并保留旧批记录。
