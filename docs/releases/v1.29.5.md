# Mnemora v1.29.5 — Safer Chinese task continuation

## Chinese task discovery

- Lets a task-resume request such as “请继续之前的数据库迁移” discover an
  existing Chinese task record through bounded word segmentation.
- Keeps the original full query for exact matching and ignores common
  continuation filler terms.

## Conservative task selection

- Preserves the existing ambiguity boundary: a request such as “继续部署”
  returns all matching task candidates rather than selecting one automatically.
- Applies the same result through the Inspector and the `mnemora resume`
  command, without writing task state or memory.

## Verification

- Adds regressions for unique Chinese task discovery, ambiguous matching, and
  the Inspector and CLI projections.
