# Mnemora v1.28.1 — Release Verification Repair

## Reliability

- Corrects schema-version expectations in every historic additive-migration
  test after the v80 first-use acceptance migration. The tests now verify the
  actual supported schema while retaining their original migration fixtures.
- Makes the current first-use acceptance record deterministic when multiple
  verifications begin in the same millisecond. Record selection now follows
  SQLite insertion order rather than a random UUID, so a prior verified record
  cannot mask a newly expired verification.

## Validation

- Runs the complete repository `verify` suite under Node.js 24.19.0 before
  publication. The release workflow still requires successful Windows and
  Linux CI for this exact tagged commit.
