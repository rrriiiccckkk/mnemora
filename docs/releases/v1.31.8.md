# Mnemora v1.31.8 — Owned test fixtures and deterministic cleanup

- Centralizes file-backed fixtures in `tests/helpers/temp.mjs`: each run owns a unique directory below the system temporary directory instead of writing into the repository's `.tmp`. Migrates 51 existing test files and the smoke, Inspector and harness-graduation scripts.
- The serial unit runner, smoke and file-backed benchmarks execute native SQLite work in a child process. The parent removes its owned root after that child exits on success or failure, avoiding retained native handles on Windows. Focused unit-test file arguments and the task-resume benchmark use the same managed runner.
- Cleanup validates root location, ownership and directory identity; child borrowers cannot remove the parent's root, and a replaced root junction is refused. Cleanup errors remain visible without discarding the original failure or test exit code.
- Adds regressions for successful and failed workers, real SQLite fixtures, smoke initialization/shutdown failures, and unsafe cleanup targets. A source guard prevents direct temporary allocation and repository `.tmp` fixtures from returning. Test concurrency remains one.
- Records the operator's maintenance lessons, including which settings are deployment-specific rather than product defaults. Ignores `dist.bak-v*` backups without deleting them.
- No schema migration, dependency update, memory policy, configuration default or embedding identity changes. This is test/release hygiene, not evidence of improved model performance. It does not delete historic temporary directories or validate the operator's Mac deployment; abrupt termination of the parent or host is outside the normal-exit cleanup guarantee.
