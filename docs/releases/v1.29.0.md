# Mnemora v1.29.0 — Reliable Task Continuation

## Lifecycle reliability

- Prevents an explicit new terminal entry ID from being mistaken for a prior
  turn solely because its message position was reused.
- Carries a durable excluded-agent decision through compatible `afterTurn`
  callbacks without retaining excluded message content.

## Task continuation

- Adds schema v82, allowing a confirmed TaskOutcome to name one exact linked
  Decision action and record whether it was attempted, partial, completed,
  failed, cancelled, or superseded.
- Produces a conservative, source-linked continuation view that separates task
  progress, constraints, blockers, planned decisions, history, and items that
  require reconfirmation. Invalidated evidence never remains active state.
- Treats Decision validity windows inclusively and keeps future actions out of
  current next steps.

## Evaluation

- Adds a 24-sequence synthetic multi-session task-resume benchmark and a
  three-arm comparison contract for no-memory, simple-retrieval, and Mnemora.
  The comparison reports `real_effect_experiment_not_run` until authorized,
  de-identified measurements are supplied; it makes no model calls.

## Validation

- Runs `npm run check`, `npm test`, `npm run benchmark:task-resume`,
  `npm run plugin:validate`, and `npm run plugin:official:compat` with Node.js
  24.19.0. The official compatibility command confirms the known OpenClaw
  2026.9.2 advanced-metadata gate rejection; it is not a claim of host
  acceptance. The release workflow still requires successful Windows and
  Linux CI for this exact tagged commit before it creates the GitHub release.
