# Mnemora v1.31.0 — Continuity reliability

## Long-history task continuation

- Task-resume projections now identify the specific state sections limited for
  presentation in `truncated_sections`.
- State resolution still considers every accepted outcome, decision,
  replacement, constraint, blocker, expiry, and evidence state before any
  section is limited for display.
- The existing `truncated` field remains as a compatibility-friendly aggregate
  indicator.

## Inspector and CLI

- The Inspector names only the sections with additional retained records.
- Ambiguous task-query candidate lists also say when additional candidates are
  not displayed.
- The CLI returns the same source-linked, per-section metadata.

## Verification

- Long histories keep a linked completed action resolved while separately
  reporting pending-state presentation truncation.
- Inspector browser coverage verifies the visible per-section notice after its
  configured display limit.
