# Mnemora v1.14.1 — Configuration Operator Skill

## Packaged configuration guidance

- Expanded the bundled `mnemora` skill from corpus-only guidance into an
  operator guide for configuration inspection, ContextEngine setup, retrieval,
  embeddings, bounded capture, corpus/artifact storage, governed cognition,
  tool surfaces, and compatibility keys.
- The skill now directs an agent to inspect active configuration and observed
  status before proposing the smallest possible patch. It redacts secrets and
  local paths, preserves unrelated host settings, and distinguishes configured,
  selected, and observed runtime state.

## Safety clarifications

- `unifiedRetrieval.shadowMode` is correctly documented as telemetry after an
  ordinary automatic-attachment attempt, not a no-injection dry run. Leave
  `unifiedRetrieval.enabled` false when automatic attachment is not wanted.
- Selecting Mnemora's ContextEngine slot, replacing another memory plugin,
  enabling model-backed work, and changing scope remain explicit user choices.
- The guide does not revive deprecated hook-based recall configuration and
  preserves the public ContextEngine as the sole automatic attachment path.
