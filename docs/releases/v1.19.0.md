# Mnemora v1.19.0 — Deterministic Schema-Drift Reconciliation

## Evidence-backed ontology coverage

- `develops` now accepts a `company` developing a `product` or `concept`.
  This covers directly evidenced work such as a company developing a named
  technical approach; it never infers an entity's identity or changes a graph
  edge.
- Existing `person → product|technology uses` support remains unchanged.

## Upgrade behavior

- Schema v77 deterministically reviews every unresolved historic schema-drift
  candidate against the current vocabulary during upgrade.
- Candidates that are now valid receive durable `endpoint_now_allowed`
  invalidation metadata. The migration writes no entity, edge, observation,
  evidence, PPR, or traversal state.
- The read-only decision gate therefore reports current invalidation outcomes
  without first depending on a worklist read side effect.

## Compatibility

- No configuration defaults changed.
- `related_to` retains its current PPR multiplier and ReasoningMemory delivery
  remains shadow-only.
