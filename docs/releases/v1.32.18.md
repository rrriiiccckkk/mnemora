# v1.32.18 — Runtime observation and independent recall evaluation

Runtime logs now preserve bounded status, elapsed time and usage metadata through
OpenClaw's public single-string logger. Earlier event titles alone did not prove
successful classification or known usage. Objects and provider error bodies are
excluded, and logging failures remain fail-open.

An offline recall-relevance evaluator separates harmful deletions from existing
retrieval misses, includes independent paired task completion, and subtracts
adjudication, retry and remediation costs. It checks disjoint tuning/test IDs,
subtraction-only suggestions and preregistered numerical limits. Reports contain
aggregates and a plan digest rather than reference IDs or source text. Synthetic
labels or missing task/cost evidence withhold review; eligibility never enables
filtering. Independent review provenance and prior plan freezing still require
operator-controlled records.

A bounded isolated HTTP trial command uses the same endpoint/model/API-key
contract for local or remote services, without opening a memory database or
changing host configuration. The current configured service returned an HTTP
error in the synthetic trial; original selection was preserved, no retry was made,
and usage remained unknown. This is not classifier quality or savings evidence.

Node 26.5.0 becomes the development default. Supported patch lines retain SQLite
compatibility boundaries; CI covers Node 24.19.0 and 26.5.0 on Linux and Windows.
Build/package verification continues to reject stale distribution artifacts.
