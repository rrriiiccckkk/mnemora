# v1.32.14 — One configurable semantic classification API

A single systemone-compatible evaluation API accepts a candidate, bounded source evidence and optional user/task/session context. Endpoint, model and named-environment Bearer authentication are configurable, so switching services does not require a code change. Both plugin schemas expose the same off/shadow configuration; there is no enforcement mode.

The public application API and `mnemora cognition classify candidate.json --config classifier.json` return bounded typed shadow labels, full retention-scope probabilities, an advisory recommendation, elapsed time and reported token counters. The operator command never opens a memory database. Enabled ingestion returns one source-level semanticShadow report without changing existing confidence, source authority, graph persistence or belief formation.

Known-sensitive inputs and recognized credential/passport/payment patterns are blocked before the optional request. This is not a universal detector or a replacement for existing Journal/extraction privacy policy. Requests are bounded, cancellable, stream-limited and never automatically retried. Failed or uncertain results defer; positive known token counters survive a malformed typed answer. Raw service responses and keys are never returned.

Defaults remain off. Tests use synthetic replies and a real isolated loopback HTTP fixture, not paid provider calls. There is no model-quality, calibrated threshold, measured speed or token-saving claim. Independent evaluation remains required before 1.33 enforcement.
