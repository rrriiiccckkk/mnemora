# Mnemora v1.21.0 — Graph Review Operator Closure

## Read-only review access

- The local CLI now exposes scope-local graph-review worklists for `pending`,
  `rejected`, and `invalidated` outcomes. Operators can inspect those durable
  dispositions without accessing SQLite directly.
- Worklist inspection remains read-only and does not scan, change a review
  decision, alter PPR, or enable ReasoningMemory delivery.

## Audited anomaly cleanup

- `review anomalies preview` and `review anomalies confirm` provide the
  existing anomaly cleanup through a dedicated preview/confirm flow.
- A confirmation requires its exact fresh preview hash and writes the existing
  cleanup audit receipt before retiring the selected active anomaly edge.
- Cleanup is scope-safe: an edge with observations in another scope is not
  eligible for a scope-local preview or deletion. This prevents one scope from
  retiring shared graph state.

## Documentation and compatibility

- The README now documents the separate bounded semantic-vocabulary scan: it
  only collects proposals, and accepted semantic-pattern reviews never promote
  vocabulary automatically.
- No configuration defaults changed and no schema migration is required.
- PPR/traversal policy and ReasoningMemory delivery remain unchanged.
