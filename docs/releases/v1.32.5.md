  source/window omissions and keyed content fingerprints, without prompt or record text.

  independent reasoning provenance gaps remain explicit.

  at most 24 hours are required. Capture stops after 20 records; writing is bounded,
  atomic and fail-open for the original context result. Existing metadata is not
  automatically removed when capture expires.

  The plugin's normal context and memory behavior remains available.

verification or model efficacy. This feature cannot reconstruct the missing W1
