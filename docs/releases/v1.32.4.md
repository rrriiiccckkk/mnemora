# Mnemora v1.32.4 — Derived-memory provenance boundaries

- Recalled summaries and Episodes explicitly identify derived paraphrases as
  `not_verified`; record associations and confidence are not claim verification.
- Bounded, scope-local original-source windows include role, reference, time
  and truncation. Multi-level summaries can reach original event text.
- Windows are refreshed at prompt packing, so an earlier find cannot replay
  source text after forgetting. Existing context-safety sanitization is retained.
- Compaction recovery uses the same distinction and budgeted source windows,
  preserving the fresh tail or omitting the optional summary when it cannot fit.

Schema 84 and retrieval authority/ranking weights are unchanged. Added evidence
text counts against the existing prompt budget. This is not a semantic verifier
and does not repair stored summaries or independently prove execution.

The reported deletion-object confusion was not reproduced on the user's Mac;
the first faulty node remains unlocated. Offline tests cover provenance exposure
and safety boundaries, not model compliance or efficacy. No production database
access, paid model calls, or pilot gate changes are part of this development.
