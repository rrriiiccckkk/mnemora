# v1.32.17 — Verify the installable build, not only the version number

Build and prepack now remove old generated output, compile current source and produce a manifest binding runtime version, schema, source fingerprint and all distribution file hashes. The final npm tarball is unpacked and verified on Linux and Windows CI; Release publishes the verified tgz and SHA256SUMS for the exact tagged commit. Source archives still require a build.

The verifier detects source/dist drift, missing/modified output and stale modules. Independent project-memory snapshots are keyed by distribution content as well as version, preventing same-version rebuilds from reusing a stale snapshot. This release does not change memory schema85 or recall policies, and does not reinstall or restart the daily host.

At inspection the installed 1.32.16 source and dist were already schema85, with a later dist rebuild. The earlier reported schema84 state was not available for forensic confirmation; this release fixes the verified packaging gap rather than claiming its original cause is proven.
