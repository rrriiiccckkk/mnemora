# Mnemora v1.32.2 — One-command three-arm regression

- A separate `regression` entrypoint freezes materials and explicit call/token
  allowance, runs three arms serially, validates evidence and produces private
  fact reports plus an optional-review packet without external preregistration.
- Identical resumes never redispatch completed cells. Changed materials, code
  or allowance, ambiguous costs and invalid responses remain fail-closed.
- Reports separate input/output tokens and preserve partial-cost limitations.
  Output snapshots are private and immutable; terminal summaries omit raw text.
- Regression purpose is frozen and rejected by formal registration and measured
  export. The original formal experiment flow and v1.33 value policy are intact.

Schema 84, product defaults and model identities are unchanged. No database
migration, production database access or real paid experiment is part of this
development. Existing precomputed memory payloads are still required; the
runner does not secretly call an extractor or AI judge.

Reports are regression evidence, not efficacy claims. AI review may be added
by the coordinating agent but is not human verification; correctness labels
are not automatically fabricated. Token allowance is not a provider billing
cap. Historical formation, review calls and production end-to-end costs remain
outside the reported inference usage.

Node 24.19.0 complete local verification passed: 1051 unit tests passed, one
POSIX-only permission test skipped on Windows, and all existing benchmarks,
plugin validation, smoke and version checks passed. The known OpenClaw 2026.9.2
advanced-metadata compatibility rejection remains an expectation gate, not
universal host compatibility. Standards and Spec reviews closed the regression
packet's inappropriate formal-audit requirement.

Publication also requires exact-commit successful Windows/Linux CI.
