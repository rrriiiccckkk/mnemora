# Mnemora v1.17.0 — Graph Review Decision Gate

## Operator measurement, not an automatic policy

- Adds the CLI-only command:

  ```bash
  MNEMORA_DB=/path/to/mnemora.db node dist/cli.js review gate --scope default
  ```

- The scope-local JSON report combines the current graph hygiene/topology
  diagnostic with aggregate pending, accepted, rejected, and durably
  invalidated outcomes for structural refinement, semantic labels, and
  semantic-vocabulary review.
- The report intentionally does not scan, confirm a candidate, alter a graph
  edge, mutate review state, change PPR, or enable ReasoningMemory delivery.
  It records that these actions remain unchanged so an operator—not the
  report—decides whether real evidence justifies a later policy change.

## Compatibility and validation

- No schema migration or configuration change. The command reads existing
  scope-local records only.
- Adds module and CLI regressions for aggregation, scope isolation,
  read-only graph invariance, bounded CLI arguments, and absence from the
  agent-facing OpenClaw tool surface.
