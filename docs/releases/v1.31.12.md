# Mnemora v1.31.12 — Exact attachment evidence safeguards

- Adds opt-in bounded assembly receipts for actually attached unified memory
  documents, beliefs and decisions. Record-version and projection hashes do not
  persist prompt text, user questions or session identifiers.
- Rechecks versions after asynchronous work; edited, forgotten, unreadable or
  unavailable recorded sources/targets stop participating in evidence review.
- Adds explicit preview/confirm source-linked operator labels for assistant
  citations, user confirmations and corrections. No automatic label inference,
  causal turn attribution, confidence update or canary calibration is performed.
- Existing read-only usefulness review includes individual receipts, without
  treating aggregate usage or a partial evidence window as an efficacy rate.
- Schema 84 adds two dedicated tables with scoped retention/cascading cleanup;
  schema83 upgrades preserve prior records without fabricating historical
  receipts. Backup/restore and restart are covered by isolated fixtures.
- Model identity, retrieval budgets, serial test execution and existing defaults
  stay unchanged; evidence recording is disabled unless explicitly enabled.

Local Node 24.19.0 `npm run verify` passed: 983 unit tests (19 new behavior and
migration regressions), all benchmarks, plugin validation/smoke and version
consistency. The official SDK compatibility expectation gate retains its known
2026.9.2 advanced-metadata rejection; this is not universal host compatibility.
Publication additionally requires successful Windows/Linux CI for this exact
commit. Real task-resume efficacy and Mac deployment remain unmeasured here.
