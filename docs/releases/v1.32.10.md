# v1.32.10 — Reliable, compact project adviser requests

This release combines project adviser continuation reliability with prompt
overhead reduction. Host retries could replace the latest question with a
continuation instruction while the bridge forwarded a large unrelated host
prompt. The bridge now pins the original command question across retries and
forwards only the actual admitted memory attachment, preserving source evidence.

A bounded JSON answer must carry the matching request ID. Unstructured and
wrong-request replies fail instead of being accepted; measurement records
distinguish this validation from transport status. The contract check does not
prove factual correctness. No authority, scope or retrieval budget is widened.

One real project invocation reduced forwarded input to 4614 characters from
an earlier 48794-character observation. Different questions and unchanged
startup overhead prevent a causal latency or efficiency conclusion. Provider
token usage remains unavailable. This is repository development tooling, with
no schema or daily-host policy changes.

ACL skip on macOS, all script benchmarks and 17 task-resume checks. The isolated
real-model restart/task-recall check passed. Publication additionally requires
