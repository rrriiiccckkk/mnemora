# Mnemora v1.31.5 — Task-resume evidence coverage

- `resume` now reports `memory_evidence` for a selected task and for bounded task candidates. It distinguishes readable, active source evidence from an accepted current Decision or TaskOutcome with active evidence.
- When the task has readable sources but no accepted current state, the reconfirmation message identifies a memory-coverage gap. It does not claim that the real-world task state is unknown or promote the source text to an accepted outcome.
- Forgotten, inactive, and hash-only sources are not reported as readable. The projection remains read-only and retains its existing scope, acceptance, and reconfirmation gates.

This change makes the two sources of uncertainty inspectable. It does not establish improved continuation accuracy on the previously reported four-case Mac comparison; that requires a matched rerun with the final model-visible inputs.
