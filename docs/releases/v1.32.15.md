# v1.32.15 — Safe semantic classification observation

Configured shadow classifier calls now emit a content-free info event from both ordinary and admitted runtime graph handles. Events expose status, recommendation, elapsed time, known/unknown token usage and applied=false. They omit input, evidence, source/session/scope identifiers, endpoint, model and credentials. Observer failures do not change classifier results or ingestion; off mode remains silent.

The session persistence investigation identified nine historical host-side session-rebound records with admission/terminal generation mismatches and zero plugin delivery attempts. These are rejected before Mnemora commitTurn. This patch documents the evidence and limits; it does not bypass the host fence, alter the daily outbox, or claim recovery of rejected historical turns. Classification observations are not independent quality evaluation, and 1.33 enforcement remains gated.
