# Mnemora v1.29.1 — Task continuation reliability fixes

## Correct action state

- Resolves the full accepted task outcome history before limiting the resume
  response, so a previously completed action cannot reappear as a next step
  merely because later records exceeded the display limit.

## ContextEngine compatibility safety

- Adds schema v83 one-way compatibility fingerprints for durable turns and
  excluded-agent suppression records.
- An ID-less legacy `afterTurn` callback now needs both the bounded public
  position range and matching public-message fingerprint before it is treated
  as the already-committed turn. A different compacted turn at reused
  positions is captured normally.
- A durable worker exclusion now remains effective when its compatibility
  callback omits both `sessionKey` and message IDs, without storing the
  excluded message text.

## Validation

- Runs TypeScript checks and focused ContextEngine/task-resume regression
  tests with Node.js 24.19.0. The release workflow still requires successful
  Windows and Linux CI for this exact tagged commit before publishing.
