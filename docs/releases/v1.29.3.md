# Mnemora v1.29.3 — Trusted automatic context admission

## Reliable prompt injection

- Unifies automatic context admission for unified retrieval and graph
  supplements, so rejected, contradicted, superseded, or source-invalid claims
  cannot reach an Agent prompt through a secondary path.
- Keeps admitted ReasoningMemory available for manual audit while reserving
  automatic delivery for its governed runtime path.
- Propagates forgetting through transitive summary dependencies, preventing a
  forgotten source event from reappearing through a higher-level summary.

## Budget consistency

- Uses one CJK- and astral-aware token estimator for retrieval and context
  assembly.
- Enforces the configured budget against the final rendered attachment,
  progressively reducing candidates while retaining compact canonical
  provenance.

## Verification

- Adds regressions for rejected automatic evidence, governed reasoning
  delivery, transitive summary forgetting, CJK packing, and the legacy
  128-token attachment contract.
