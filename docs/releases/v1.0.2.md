# Mnemora v1.0.2

## Integrity and extraction hardening

- Makes every local compaction entry point use the durable Journal's active
  volume for thresholding, accounting, and target selection. A host callback's
  per-turn token delta can no longer suppress `compact()` or `maintain()`.
- Bounds smart extraction inside an explicit untrusted-turn envelope, escapes
  tag-like input, and accepts a bounded JSON code-fence response from a model.
- Rejects impossible explicit expiry dates (including invalid zero fields and
  calendar rollovers), while accepting valid four-digit years outside 2000–2099.
- Canonicalizes lifecycle overlay scopes consistently on lookup, so a valid
  non-canonical caller scope no longer silently loses its tier decoration.
- Rephrases legacy release-era source comments as schema-version terminology;
  no runtime schema migration is introduced by this patch.

## Verification

Validated on Node.js 24 with the complete verification suite, including new
regressions for explicit and maintenance compaction with a delta-only host,
untrusted smart-extraction input and fenced JSON output, calendar validation,
and scope normalization.
