# Mnemora v1.0.0

Initial public release of Mnemora, a local-first, evidence-first memory runtime
for persistent OpenClaw agents.

## Included

- Public ContextEngine-based Journal capture, bounded source-linked compaction,
  restart-safe assembly, and unified memory retrieval.
- Local SQLite storage for graph evidence, memory documents, episodes,
  artifacts, beliefs, decisions, corrections, and audits.
- Bounded lexical, semantic, and hybrid retrieval with scope isolation,
  provenance, freshness, token budgets, diversity, and optional reranking.
- Explicit safety controls for extraction, candidate admission, verification,
  governance, provider migration, retention, forgetting, and recall delivery.
- Local Inspector, operator CLI, structured diagnostics, and offline quality
  evaluation.

## Compatibility

- Requires OpenClaw `2026.6.11+` and Node.js `24`.
- The SQLite schema is initialized locally and all optional model, network,
  compaction, strict policy, and delivery paths remain opt-in.
- Mnemora does not read, copy, or migrate another plugin's private storage.

## Verification

The v1.0.0 release runs the full Node.js 24 verification suite: typecheck,
unit tests, build, smoke tests, plugin validation, official compatibility gate,
release validation, and offline benchmarks.
