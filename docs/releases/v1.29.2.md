# Mnemora v1.29.2 — Long-sequence task continuation verification

## Task continuation regression coverage

- Adds an end-to-end restart regression for a replaced decision, partial
  progress, failed attempt, accepted recovery, cancelled work, retained
  history beyond the display limit, and evidence forgetting.
- Confirms that a small response `limit` affects presentation only: it cannot
  reintroduce accepted completed, cancelled, or replaced work as a next step.

## Offline evaluation

- Expands the synthetic task-resume benchmark from the previously executed 24
  cases to 26 cases, including the pre-existing restart case and a new long
  state-transition sequence.
- Adds the `long_sequence` category while preserving the local-only,
  model-free evaluation contract and its source-provenance checks.

## Handoff

- Updates the development handoff with the v1.29.1 release evidence, the
  remaining identity boundary for ID-less callbacks, and the next evaluation
  priorities.
