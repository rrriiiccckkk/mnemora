# v1.32.16 — Recall relevance shadow P0

Its endpoint/model/apiKey/timeoutMs configuration mirrors the existing reranker keys while using systemone-compatible typed questions. One bounded request makes subtraction-only suggestions; no retries or enforcement are available. Failure preserves baseline.

The original and advisory selection use the same packer and budget. Advice is restricted to the actually packed baseline, without backfill or newly attached graph supplements. Actual prompt and messages remain unchanged. The existing bounded unified recall repository exposes content-free candidate-hash diffs, status, elapsed time and known/unknown usage; schema v85 preserves historical rows. No excerpt or raw model response is persisted.

Synthetic contract tests establish privacy, cancellation, fallback and prompt parity, not calibrated quality or savings. Independent gold labels, frozen thresholds and task-level evaluation remain required before filtering. Escalation remains out of scope. Daily-host configuration is not changed by this release.
