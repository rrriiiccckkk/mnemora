# Mnemora v1.31.3 — Release wait hardening

- Extends the release workflow's exact-commit CI wait from 15 to 25 minutes,
  with a 35-minute job timeout. The CI matrix allows each operating-system job
  up to 20 minutes; this avoids false release failures when valid CI completes
  after the former wait window.
- Keeps the requirement for successful Windows and Linux CI before publishing
  a tagged release.
