# Mnemora v1.28.2 — Context Engine Tool-Result Integrity

## OpenClaw context-engine compatibility

- Declares Mnemora as an OpenClaw `context-engine` plugin in its manifest, so
  slot selection uses the host's explicit plugin capability contract.
- Recognizes OpenClaw's `toolResult` host-message role alongside the legacy
  `tool` spelling in context assembly, durable Journal capture, and optional
  tool-payload artifact handling.
- Preserves the complete current-turn suffix—current user request, assistant
  tool call, and tool result—verbatim when it exceeds the advisory context
  budget. This prevents a tool continuation from reaching the model without
  the result required to complete it.

## Validation

- Adds a regression test using OpenClaw's actual `toolResult` message shape
  and a deliberately over-budget tool result.
- Runs type checking and all 847 unit tests with Node.js 24.19.0. The release
  workflow still requires successful Windows and Linux CI for this exact
  tagged commit before publishing the GitHub release.
