# v1.36.0 — Semantic recall that adds instead of filters, calibrated for Chinese

## Highlights

- **Semantic recall now adds instead of filtering.** With embeddings on, the semantic neighbourhood and the 0.15 term floor decide whether memory is attached at all. Once a packet is open, lexical hits are no longer dropped one by one for being outside the neighbourhood. With `all-minilm`, multi-session answer accuracy rose from 47.9% to 56.2% (lexical only: 48.8%, bm25: 41.3%; 121 questions, MiMo V2.6 Pro). Abstention stayed at 12/12, and foreign- and off-topic-question attachment was unchanged (55.2% / 33.1%).
- **Thresholds calibrated per embedding model.** When `semantic.minSimilarity` and `semantic.gateSimilarity` are not set, Mnemora picks the pair calibrated for the configured model. The model name is matched with any Ollama `:tag` or `vendor/` prefix ignored.

  | Model | `minSimilarity` | `gateSimilarity` |
  |---|---:|---:|
  | `all-minilm` (English only) | 0.45 | 0.2 |
  | `paraphrase-multilingual-MiniLM-L12-v2` | 0.65 | 0.3 |
  | `bge-small-zh-v1.5` | 0.6 | 0.45 |
  | Ollama `paraphrase-multilingual` (mpnet) | 0.65 | 0.35 (provisional) |
  | any other model | 0.45 | 0.2 |

  On Chinese LongMemEval_S validation questions with `bge-small-zh-v1.5`, evidence-turn hit is unchanged at 79.2% (lexical only: 70.8%). Foreign-question attachment fell from 97.9% to 58.3%, and off-topic attachment from 89.6% to 31.2%. That is the same level as English.
- **English-only models skip non-Latin prompts.** On Chinese history, `all-minilm` was worse than lexical recall: it ranked the evidence 42nd at the median and attached memory to every off-topic prompt. With it, prompts in Chinese, Japanese, Korean or other non-Latin scripts now skip semantic recall and behave as without embeddings.
- **Calibrate your own model.** `npm run eval:calibrate-semantic` measures the cosine distributions of evidence, foreign questions and off-topic prompts on a LongMemEval-format dataset. Use it for models that are not in the table.
- **Abstention measured with two reading models.** Hosts do not keep one model, so abstention was measured with `mimo-v2.6-pro` and the smaller `mimo-v2.6-flash`, using a host-agent prompt. Attached memory costs both readers 5 to 6 of 30 abstentions. The failures answer from on-topic near misses that no relevance threshold separates from answerable questions. A "may not contain the answer" note in the packet header gave no net gain for either model and was not adopted. Retrieval is unchanged.

## Behaviour changes (please read before upgrading)

1. **Only with embeddings on.** Lexical-only recall (the default) is unchanged.
2. **Default thresholds depend on the model.** `semantic.minSimilarity` and `semantic.gateSimilarity` no longer have fixed schema defaults. If you use a multilingual model and relied on the old 0.45 / 0.2 defaults, recall becomes stricter. Set both values explicitly to keep the old behaviour. Explicit values always win.
3. **Packet gate.** With embeddings, records are attached only when at least one record passes the gate. A record passes if it is semantically close, carries an exact identifier, or is a lexical hit inside the semantic neighbourhood with term match ≥ 0.15. Once the gate is open, each record is judged as without embeddings. An operator-set `minQueryMatch` still applies to each record. Records without vectors are not gated.
4. **English-only models.** With `all-minilm`, a prompt in non-Latin script runs lexical recall only.
5. No schema migration (still v88).

## Fixes

- `scripts/evaluate-longmemeval.mjs` reads `.json.gz` datasets, uses Chinese off-topic prompts for Chinese data, and accepts `MNEMORA_EVAL_MIN_SIMILARITY` / `MNEMORA_EVAL_GATE_SIMILARITY`.
- `scripts/evaluate-longmemeval-qa.mjs` adds `MNEMORA_QA_PROMPT=agent`. In this mode the memory packet goes in a system message and the user message is the bare question, as with a host agent.
- The usage guides (English and Chinese), `docs/recall-quality.md` and the roadmap document the model table, the calibration and the abstention results.

## Known limits

- Chinese calibration uses 48 questions per set (one question is about 2 points). The validation set is machine translated.
- The Ollama `paraphrase-multilingual` pair comes from 24 questions and was not validated. `bge-m3` is not calibrated.
- Chinese results are retrieval-only. There is no end-to-end QA run in Chinese.
- With embeddings, single-session evidence recall is slightly below lexical only.
- Abstention: 30 questions per arm (one question is 3.3 points), and a few verdicts are judge noise. All readers are from one vendor.
