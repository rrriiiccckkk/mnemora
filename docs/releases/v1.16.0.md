# Mnemora v1.16.0 — Review-Driven Vocabulary Evolution

## Small, evidence-backed vocabulary

- Adds `kg_review` `kind: "semantic_vocabulary"` for the bounded lifecycle of
  five domain-neutral labels: `located_in`, `member_of`, `created_by`,
  `authored_by`, and `based_on`.
- A proposal is collected only from active same-scope `related_to` evidence
  with direct ordered wording and confidence at least `0.85`. It becomes
  reviewable only after three observations from at least two sources.
- Preview/confirm acceptance is scope-local. It enables only future,
  per-edge `related_edge_semantics` proposals; it never writes a graph edge,
  rewrites historical evidence, changes PPR or traversal, or enables automatic
  extraction or recall.

## Explicit inspection only

- `kg_related` accepts `semantic_predicates` for exact, operator-approved
  dynamic-label inspection. Omitted predicates remain structural-only.
- An individual label still needs its own matching preview/confirm review.
  Dynamic semantic labels are source-linked read projections, not graph arcs
  and not automatic context attachments.

## Migration and compatibility

- Schema version advances from `74` to `75`. The migration adds the vocabulary
  candidate/evidence/review tables and widens the existing reviewed-label
  predicate contract from the fixed built-in list to a bounded string.
- Existing semantic review rows and receipts are copied atomically. No
  migration scans evidence, creates labels, changes graph facts, or changes
  default configuration or recall behavior.

## Validation

- Adds regressions for thresholded multi-source discovery, scope-local
  acceptance, rejected-vocabulary inertness, per-edge confirmation, explicit
  dynamic-label visibility, topology invariance, and the v74-to-v75 migration.
