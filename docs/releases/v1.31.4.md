# Mnemora v1.31.4 — Explicit task links for reviewed intake

- A reviewer can select an active, same-scope task Episode with `--task-ref` while previewing and confirming a Reasoning Intake candidate. The selected task is displayed in the preview and bound to its confirmation hash.
- Confirmed Decisions and TaskOutcomes selected this way appear in that task's read-only `resume` projection. Without an explicit selection, candidates retain their original conversation-event anchor; a same-turn task episode is not treated as proof of task identity.
- Cross-scope, missing, inactive, and non-task Episode references are rejected. Candidates remain pending until explicitly confirmed.

This closes an operator-confirmation-to-resume linkage gap. It does not change automatic recall, claim that unreviewed history is an accepted task state, or establish an improvement on the separately reported four-case Mac comparison. That comparison used an isolated `resume`/retrieval setup and requires a matched rerun before any effect claim.
