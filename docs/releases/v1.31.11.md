# Mnemora v1.31.11 — Recall usefulness evidence boundaries

- Adds a read-only `cognition feedback evidence <target-ref>` worklist over an
  explicit existing snapshot. It separates actual-attachment aggregates,
  bounded canonical-reference mentions and existing operator-asserted feedback.
- Assistant citations do not imply endorsement; user mentions remain review
  candidates, not automatically inferred confirmations or corrections.
  Corroboration and turn-level attribution remain explicitly unmeasured.
- Rechecks target/source lifecycle, excludes old/future or unreadable sources,
  and marks partial history, text budgets and uncertain capture boundaries.
  Reports expose authorized provenance refs, not message bodies or session names.
- Shares the threshold scan's read-only, no-create/no-migration database boundary.
  Exact-token, Unicode-adjacency and multipart-clipping regressions prevent false
  citation evidence.
- No schema, dependency, model or default changes. This is evidence-review
  groundwork, not completed implicit outcome capture, canary integration or
  proof of task-continuation gains. The real v1.32 experiment remains pending.
- Disables optional npm caching on Windows CI after cache compression exhausted
  the job timeout following successful verification. All verification steps and
  Linux caching remain unchanged; publication still requires both platforms.
