# Mnemora v1.3.0

## Delivery integrity and evidence semantics

- Makes the local reasoning-delivery evaluator explicitly non-causal. V2
  datasets require a declared evidence kind; only operator-declared randomized
  data with sufficient outcomes receives a point estimate and conservative 95%
  interval. Synthetic, observational, sparse, and legacy v1 data cannot make
  an efficacy claim.
- Keeps historic harmful delivery feedback immutable while allowing an operator
  circuit reset to record an append-only correction and restore the item's
  effective status. Later feedback supersedes that correction without erasing
  the audit trail.

## Migration

Schema version advances from 63 to 64. Migration is additive: it adds
`last_feedback_event_id` to delivery items and an append-only correction table.
Existing items are backfilled from their latest historic non-adoption feedback
event. It does not alter memories, evidence, strategies, scopes, or defaults.

## Compatibility

The existing effectiveness v1 dataset format remains readable, but is treated
as unattested and returns `insufficient_evidence`. No configuration default
changes in this release.
