# Mnemora v1.27.0 — Durable OpenClaw Context Turns

## OpenClaw compatibility

- Updates the supported OpenClaw host and plugin API baseline to 2026.9.2.
- Uses the current agent-harness SDK entry points and qualified session-key
  lifecycle in the standalone context-engine integration.

## Durable turn capture

- Implements the host's atomic, idempotent durable `commitTurn` contract.
  Retried accepted turns reuse their receipt, while a reused key with changed
  input is rejected.
- Adds schema v78 for opaque turn-advancement receipts. It preserves existing
  journal evidence and prevents the legacy post-turn callback from capturing a
  committed range twice.

## Validation

- Adds lifecycle, retry-collision, migration, and graduation coverage for the
  current ContextEngine contract.
