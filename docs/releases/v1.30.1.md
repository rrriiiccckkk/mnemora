# Mnemora v1.30.1 — Canonical CLI storage

## Reliable local CLI

- The standalone CLI now defaults to Mnemora's canonical
  `~/.openclaw/mnemora.db` instead of silently creating `mnemora.db` in the
  caller's current directory.
- On first creation of a persistent database, the CLI writes its exact path to
  stderr. `MNEMORA_DB` remains the explicit override for a different store.

## Unpacked plugin portability

- The build makes `dist/cli.js` directly executable on POSIX platforms, so an
  unpacked OpenClaw extension does not rely on npm having created a global bin
  shim.
- The README documents direct `node dist/cli.js` use from a plugin directory.

## Verification

- Adds end-to-end CLI regressions for canonical default selection, explicit
  database selection, creation notices, and directly invoked CLI permissions.
