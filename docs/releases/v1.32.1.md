# Mnemora v1.32.1 — Controlled-memory experiment toolkit

- A standalone three-arm runner freezes authorized case histories, cutoff
  boundaries, prompts, model settings, memory payloads and implementation
  fingerprints before registration. It does not open the production database.
- Paid model dispatch requires an explicit `--execute` and an environment-only
  API key. Requests run serially; ambiguous starts, unknown costs, invalid
  responses and budget violations stop the batch without automatic retries.
- Private evidence retains exact requests, raw responses and provider token
  usage. Resume checks reject changed materials, code or registration bindings.
- Review packets separate human annotation from execution. Export requires
  complete resolved labels and explicit collection-audit attestations before
  producing measured input for the existing comparison and value gate.
- The packaged runner, synthetic example and concise Mac handoff provide one
  repeatable workflow instead of free-form agent instructions.

Schema 84, model identities, product defaults and the registered decision
policy are unchanged. There is no database migration.

## Evidence limits

This is controlled-memory research tooling, not an autoRecall or production
end-to-end evaluation. Reported latency covers model dispatch through response
validation; historical memory formation, precomputed projection and evidence
disk writes are excluded and must be accounted for separately.

Hashes and operator attestations do not independently prove authorization,
truth, preregistration time or correct memory formation. Human audit and an
independent pre-run record remain required. Synthetic tests establish workflow
contracts, not continuation accuracy. No real paid model experiment or Mac
deployment was performed as part of this release. The v1.33 pilot gate stays
closed.
