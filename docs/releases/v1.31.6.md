# Mnemora v1.31.6 — Inspector task-resume evidence coverage

- Inspector now displays the existing `memory_evidence` checks on both task candidates and selected task details: readable task sources and an accepted current state with active evidence.
- Progress is labelled **Recorded progress** to distinguish the stored projection from a new verification of real-world task state. Source-only coverage gaps recommend inspecting evidence before asking the user to repeat progress; unavailable sources do not receive that recommendation.
- The browser uses the task-resume service's type-only result contract rather than maintaining a divergent copy. This does not bundle server or SQLite runtime code into the client.
- Browser regressions cover accepted state, source-only coverage, hash-only sources, independently evidenced accepted state, scope isolation, task selection, and refresh after forgetting. Reads remain non-mutating.

This patch changes Inspector presentation, not the model-visible resume projection or automatic recall. It does not demonstrate improved accuracy on the four-case Mac comparison; that still requires a matched rerun.
