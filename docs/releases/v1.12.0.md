# Mnemora v1.12.0 — Related-Edge Admission and Topology Assessment

## Safer fallback-edge admission

- New `related_to` edges require retained evidence. Direct structured ingestion
  rejects an empty evidence span.
- Automatic extraction additionally requires that a `related_to` evidence span
  is a contiguous quote from its input. Vague association, co-occurrence, and
  unsupported inferred relevance are dropped rather than persisted as an edge.
- The default `quality.relatedToMinConfidence` is now `0.85`. An explicit
  operator value remains unchanged, and existing graph rows are not rewritten.

## Read-only topology assessment

- `kg_review` with `kind: "hygiene"` now reports a bounded, scope-local
  `related_to_topology` comparison of three policies: current `0.35` PPR
  multiplier, `0.105` downweight, and exclusion.
- The report includes weak components, isolated nodes, largest-component ratio,
  and representative-seed top-k Jaccard changes. It excludes the seed itself
  from top-k comparison.
- This is diagnostic only: it does not change live PPR, traversal, stored
  evidence, or historical edges. Scheduled hygiene deliberately omits the
  potentially expensive comparison; it is available through explicit review.

## Compatibility and migration

- No schema migration. Existing data and explicit quality configuration remain
  valid.
- `related_to` topology policy remains unchanged in v1.12. The diagnostic is
  the decision gate for the v1.13 topology change.

## Validation

- Added regression coverage for source-grounded fallback extraction, empty
  fallback-edge evidence rejection, default threshold configuration, topology
  component changes, scope isolation, and non-mutation of the live PPR
  projection.
