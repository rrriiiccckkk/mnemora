# Mnemora v1.24.0 — Graph Projection Seam and CI Stability

## Internal reliability work

- Graph traversal, context compilation, semantic-label projection, and source
  attribution now live in one internal, read-only graph-projection module.
  `GraphologyStore` retains all existing public methods and observable
  behavior.
- SQLite graph-row decoding is shared by the read-model modules, preventing
  lexical, semantic, and traversal paths from drifting apart.

## CI stability

- The URL deadline regression test now uses the test runner's bounded timeout
  instead of a scheduler-sensitive wall-clock threshold. It still verifies
  that a resolver ignoring cancellation returns a bounded `timeout` result.

## Compatibility

- No database migration, configuration default, new agent tool, or recall/PPR
  policy change is included.
