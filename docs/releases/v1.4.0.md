# Mnemora v1.4.0

## Deterministic verification mount point

- Adds optional `reasoning-verification-v1` metadata to ReasoningMemory
  proposals. Its small, strict assertion vocabulary can describe a tool result,
  task outcome, or strategy-adoption signal without storing raw tool output,
  prompts, model output, or session data.
- The metadata is not a verifier and does not change strategy admission,
  retrieval, delivery, confidence, memory state, beliefs, facts, or graph
  edges. No model, network, or tool call is introduced.

## Migration

Schema version advances from 64 to 65. The additive migration creates nullable
`verification_json` on `mnemora_reasoning_memories`; it does not rewrite or
backfill any existing strategy, evidence, outcome, scope, or lifecycle data.

## Compatibility

No configuration keys or default behaviors change. Existing ReasoningMemory
records continue to read without verification metadata.
