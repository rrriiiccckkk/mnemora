# Mnemora v1.31.1 — Comparison budget guard

- Rejects task-resume comparison measurements that exceed the plan's per-case
  token or latency budget. This applies to tuning and held-out test records.
- Keeps exact-budget measurements valid and prevents over-budget records from
  silently contributing to reported results.
- Corrects the README count for the 26 synthetic task-resume sequences.

This release hardens the comparison contract. It does not run a model or claim
real task-resume effectiveness; v1.32.0 still requires authorized,
de-identified held-out measurements.
