# Mnemora v1.32.0 — Readable task-resume evidence

- Selected-task resume results now include bounded, source-linked readable
  Journal excerpts in `source_evidence`. Roles, timestamps and truncation are
  explicit; excerpts remain `unverified_source`, not accepted task state.
- Inspector displays those excerpts separately as plain text. Ambiguous tasks,
  invalid/forgotten sources, future messages and scope boundaries retain their
  existing safeguards; malformed timestamps no longer interrupt rendering.
- New Journal search text removes NUL before native TEXT binding, preserving
  qualifiers after the character. Captured parts and audit hashes retain the
  original content. Previously truncated stored text is not repaired.
- Stateless/ignored ContextEngine unified recall remains readable without
  writing recall counts, access reinforcement, first-use attachment validation
  or unified shadow records. Default writable-session behavior is unchanged.
- Synthetic evaluation checks source-payload safety separately from accepted
  state assertions: excerpts cannot make missing accepted state pass a test.
- English and Chinese READMEs are now concise entrypoints. Full configuration
  and operating procedures remain in the linked bilingual usage guides.

Schema 84, model identities, existing retrieval limits and configuration
defaults are unchanged. There is no new database migration.

The implementation commit `3d9e62a` passed Node 24.19.0 full verification with
1007 unit tests and Windows/Linux CI `36852586804`. The release commit also
requires its own successful exact-commit CI. The SDK compatibility expectation
gate retains the known OpenClaw 2026.9.2 advanced-metadata rejection; it does
not establish universal host compatibility.

## Evidence limits and follow-up

This is a technical release, not a successful efficacy verdict. The received
12-case exploratory comparison failed the value gate, has unresolved audit
issues and is below the registered sample requirements. Readable excerpts
address a payload gap but do not prove improved continuation accuracy.

Mac deployment, corrected annotations, matched regression reruns and a full
preregistered unseen-case experiment remain pending. Existing seen cases are
not new held-out evidence. The v1.33 pilot gate remains closed; no thresholds
or labels were changed to obtain a pass.

See [source evidence and reruns](../task-resume-source-evidence.zh-CN.md) and
[the roadmap](../roadmap.md) for the remaining work.
