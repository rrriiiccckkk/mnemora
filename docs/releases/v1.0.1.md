# Mnemora v1.0.1

## Automatic extraction observability

- Classifies failures after extraction but during graph ingestion as
  `ingestion`, rather than the unhelpful `unknown` category.
- Persists a bounded diagnostic code such as
  `ingestion_persistence_failed` in the automatic-run receipt and emits the
  same code in the warning log.
- Keeps raw error messages out of logs and SQLite receipts, so provider
  bodies, user content, credentials, and filesystem details are never exposed
  through failure diagnostics.

## Verification

Validated on Node.js 24 with the full test suite, typecheck, build, plugin
validation, smoke test, release validation, and a dedicated automatic
extraction regression test.
