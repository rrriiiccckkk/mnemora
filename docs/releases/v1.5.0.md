# Mnemora v1.5.0

## ReasoningMemory deterministic verification

This release completes the first safe feedback loop for delivered
ReasoningMemory strategies.

- Adds a local, append-only verification-event ledger (schema 66).
- An explicit delivery receipt cited by an operator-confirmed TaskOutcome
  deterministically queues outcome and adoption checks.
- Adds an operator/Provider Adapter seam for bounded contracted tool results;
  raw tool output is never accepted or stored.
- A mismatch opens the existing per-memory delivery circuit, withholding that
  strategy until an explicit operator reset. It cannot create a belief, fact,
  graph edge, or confidence change.
- Adds opt-in `cognition.reasoningRuntime.verification`, disabled by default.
  It processes a bounded local batch after a durable ContextEngine turn and
  makes no model, network, or tool call.
- Adds CLI visibility and explicit confirmation for event processing and tool
  result recording.

## Compatibility

Schema 66 preserves all existing delivery-circuit fields while widening its
reason enum, then adds the verification ledger. Existing data and default
runtime behavior are unchanged.
