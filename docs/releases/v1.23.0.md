# Mnemora v1.23.0 — Storage Read Seams and Windows CI

## Internal reliability work

- Node lexical and semantic candidate discovery, evidence hydration, and
  hybrid ranking now live in a dedicated read-only retrieval repository.
  `GraphologyStore` keeps its existing public methods, so callers and stored
  data remain compatible.
- Portable database replacement now runs through a dedicated recovery
  service. It preserves the existing transactional restore, schema
  compatibility, derived-index rebuild, and bounded error behavior.

## Verification

- CI now runs the complete Node 24 release gate on both Ubuntu and Windows.
  Playwright Chromium installation is selected per platform.
- No database migration, configuration change, new agent tool, or recall
  policy change is included in this release.
