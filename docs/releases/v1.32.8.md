# v1.32.8 — Preserve explicit task evidence in recall

Fresh-session task recall could return an older release record even when the
correct detailed completion remained in the journal. This patch makes ASCII
journal searches case-insensitive, exempts safe exact task identifiers from the
conversation length penalty, and selects matching task evidence before generic
history so final prompt packing retains it within the existing budget.

Scope isolation, confidence admission, source authority and token limits remain
in force. Secret-like labels do not receive this identifier preference. No
database migration or configuration change is required.

Synthetic regressions cover detailed completions competing with short history,
lowercase queries, identifier-prefix lookalikes, foreign scopes and confidence
floors. The isolated real-model OpenClaw 2026.9.8 check also passed fresh-session
recall after restart with a lowercase identifier at the 1500-token budget.

Local full verification passed 1084 tests, with one Windows-only ACL test
skipped on macOS, all 13 script benchmarks and 17 task-resume checks. Publication
requires successful Linux and Windows CI for this exact release commit.

See [the diagnosis and validation record](../development-recall-regression.md).
