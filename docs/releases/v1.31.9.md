# Mnemora v1.31.9 — Reference projection trust boundaries

- Applies the existing projection guard to persisted summary assembly,
  compaction transcript rewrite and all built-in reasoning adapters. Stored
  strategy/source text cannot forge a reserved `MNEMORA_*` envelope; recognized
  speaker-role lines and hidden controls are neutralized at those exits.
- Keeps original Journal, summary and reasoning records available for audit.
  Operator-confirmed provenance does not grant instruction authority.
- Removes whole-presentation character truncation from reasoning rendering.
  Oversized output is rejected by the existing UTF-8 byte contract rather than
  returning a cut-off envelope. Governed delivery retries smaller candidate
  prefixes and records budget withholding when none fits; canonical references
  remain intact and short summaries retain their trailing facts after quoting.
- Adds dedicated adversarial fixtures and regressions for capture-to-recall,
  persisted-summary reopen, transcript rewrite, three built-in adapters,
  extraction request roles, URL-to-extraction-to-recall, Unicode line separators,
  audit preservation, full references and presentation-size fitting/rejection.
- Records the [threat model](../threat-model.md) and
  [reference-authority decision](../adr/0002-reference-text-is-not-authority.md).
  These structural tests do not prove model-level prompt-injection resistance
  or improved task continuation accuracy. Some host APIs still transport the
  bounded reference region in a system-role message or prompt addition.
- No schema migration, dependency change, model identity or configuration-default
  change. Production Mac deployment is not part of this verification.

Local validation: Node 24.19.0 `npm run verify` passed, including 943 unit tests,
all repository benchmarks, plugin validation/smoke and the documented official
SDK compatibility gate. Publication requires successful Windows and Linux CI
for the exact tagged commit.
