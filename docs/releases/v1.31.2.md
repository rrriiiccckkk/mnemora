# Mnemora v1.31.2 — Comparison coverage guard

- Adds an optional, human-reviewed `irrelevantMemoryInjected` label to each
  task-resume comparison result.
- Reports held-out `irrelevant_injection` counts and rates only when every case
  in every arm has a label. Unlabelled experiments explicitly report that this
  metric was not measured; partial labelling is rejected.
- Rejects an irrelevant-memory label of `true` for the no-long-term-memory arm.

This release prepares a required v1.32.0 metric. It does not execute the
three-arm experiment or claim real task-resume effectiveness.
