# Mnemora v1.29.6 — Chinese graph lexical recall

## Graph search

- Lets graph-side lexical retrieval find a Chinese node from a natural-language
  request rather than treating the complete sentence as one trigram phrase.
- Uses bounded Chinese word and three-character candidates for FTS, while the
  `LIKE` fallback can also use short Chinese terms that trigram FTS cannot
  represent.

## Verification

- Adds a public graph-search regression for a Chinese natural-language query.
- Preserves the existing trigram migration, hybrid ranking, and graph-ingest
  regressions.
