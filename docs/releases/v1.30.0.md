# Mnemora v1.30.0 — Reliable task continuation

## Current-task selection

- Task-resume candidates now carry their source-linked current progress.
- A completed task no longer makes a matching unfinished task ambiguous or
  appears in the no-query list of tasks to continue.
- A completed task remains available through an explicit task reference, or
  when a direct query identifies only that historical task.

## Inspector and CLI

- The Inspector labels each candidate's current progress and changes the
  completed-task action to “View this task”.
- The same progress field is returned by the read-only `mnemora resume` CLI.

## Verification

- Adds end-to-end Inspector and CLI regressions across restart, correction,
  forgetting, Chinese discovery, ambiguity, and completed-task selection.
