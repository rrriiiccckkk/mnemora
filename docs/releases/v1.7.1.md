# Mnemora v1.7.1

## Packaged curation configuration

The OpenClaw entry schema now declares `cognition.reasoningCuration` exactly
as the manifest does. The v1.7.0 feature can therefore be validated, installed,
and enabled through the packaged plugin. Defaults remain disabled.

## Canonical corpus FTS recovery

Startup now checks the local derived `mnemora_corpus_chunks_fts` cache even
when the database already reports the current schema version. If that FTS table
is absent or no longer mirrors the canonical corpus chunks, Mnemora rebuilds
only the cache from those chunks in one local transaction.

This repairs an interrupted trigram-index rebuild without changing corpus
documents/chunks, graph data, memories, evidence, profiles, strategies, or the
schema version (`68`).
