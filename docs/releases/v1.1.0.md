# Mnemora v1.1.0

## ReasoningMemory cold-start safety

- Adds a short-lived, source-free delivery receipt for each governed reasoning
  strategy delivery. A receipt records only its scope, delivery run, strategy
  ID, ordinal, status, timestamps, and outcome link; it stores no prompt,
  session, task text, source content, or strategy text.
- Adds deterministic feedback from explicit operator receipt feedback or an
  operator-confirmed task outcome that explicitly cites the receipt.
- A harmful signal opens a per-memory, per-scope circuit. It suppresses that
  strategy's future retrieval while leaving its admitted state, confidence,
  personal memory, graph facts, and the scope canary unchanged. Reset remains
  preview/confirm.
- Adds CLI visibility for delivery items, feedback summaries, and individual
  memory circuits.

## Evidence before efficacy claims

- Adds an offline, de-identified delivery-effectiveness evaluator and benchmark
  contract. It reports a success-rate difference only for randomized datasets
  with at least 20 resolved outcomes per arm.
- Shadow telemetry, adoption counts, and synthetic benchmarks are explicitly
  reported as non-efficacy evidence.

## Compatibility

- Schema version advances from `61` to `62` through one additive migration.
  Existing strategies, outcomes, graph evidence, memories, and prior delivery
  runs are untouched.
- Reasoning delivery remains disabled by default. The new
  `cognition.reasoningRuntime.delivery.itemRetentionDays` option defaults to
  `30` and is bounded to `1..365` days.

## Verification

Validated on Node.js 24 with typechecking, the complete unit suite, smoke and
plugin validation gates, offline benchmarks, migration coverage, and dedicated
delivery-feedback/effectiveness regressions.
