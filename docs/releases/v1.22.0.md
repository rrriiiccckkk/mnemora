# Mnemora v1.22.0 — Semantic Vocabulary Operator Lifecycle

## Local operator workflow

- The local CLI now exposes the existing bounded semantic-vocabulary scan,
  scope-local candidate lists, and preview/confirm decisions.
- Operators can review `pending`, `accepted`, and `rejected` vocabulary
  candidates without direct SQLite access or a new agent-facing tool.

## Governance boundaries

- Collection is bounded and only records review candidates. It never rewrites
  an edge, creates a semantic label, changes graph topology, or changes
  automatic recall.
- Every accepted or rejected vocabulary decision requires a fresh matching
  preview hash and writes the existing audit receipt.
- No configuration defaults changed and no database migration is required.
- PPR/traversal policy and ReasoningMemory delivery remain unchanged.
