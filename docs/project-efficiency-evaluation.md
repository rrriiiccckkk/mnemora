The first instrumented call reported 26,247 ms total elapsed time, including
setup, inference, durable capture and Gateway shutdown. Its single public model
CLI call took 15,684 ms. Forwarded input length was 48,794 characters; this is not
a token count and includes host-supplied context. The actual OpenClaw 2026.9.8
public stateless response exposed no provider usage. Provider token usage and
monetary cost remain unknown; synthetic proxy counts were excluded. The private
measurement log links the answer and cleanup-complete record using a unique ID.

These are adviser-call timings, not total development task time or pure provider
latency. The two historical tasks lack measurements; none has a matched
no-memory baseline. No elapsed-time, token or monetary saving is established.
The task count does not turn missing measurements into completed efficacy data.
Memory answers remain references: checking source and tests was still necessary,
and no avoided inspection was claimed for this instrumentation task.

Future genuine tasks should preserve the task-start recall verdict, run IDs,
actual edits/checks, failures and any independently demonstrable avoided work.
Record task-level time separately. A comparison requires fixed conditions and
source-verified outcomes; repeated questions about this instrumentation must not
be relabeled as new tasks. Do not invent work solely to fill the sample count or
retroactively assign metrics to earlier tasks.
